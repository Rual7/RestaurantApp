# RestaurantApp - Orders Management System

This project is a Windows desktop application built with C#, WPF and PostgreSQL, implementing a complete restaurant management and online ordering system. The project focuses on clean architecture, database integration, user interaction and role-based functionality while providing a modern and interactive desktop experience.

## Features

### Guest Users
- View restaurant menu
- Search dishes and menus by name or allergens
- Create client accounts

### Client Users
- Place food orders
- View order history
- Track active orders
- Cancel active orders
- Receive discounts based on order rules

### Employee Users
- Manage categories, dishes, menus and allergens
- View and manage all restaurant orders
- Update order statuses
- Monitor low stock dishes
- Generate reports

## Technologies

- C#
- WPF (.NET)
- PostgreSQL
- Entity Framework Core
- MVVM architecture
- Npgsql

## Purpose

This project was created as a learning exercise to explore WPF desktop development, focusing on:

- building a responsive desktop UI
- applying MVVM principles
- designing a normalized relational database
- implementing layered architecture
- managing orders and business logic
- integrating Entity Framework Core with PostgreSQL
- using stored procedures and database functions
- handling authentication and role-based access
